# 🏋️‍♂️ Gym & Online Coaching Management System

An integrated web and mobile platform designed to simplify **gym management**, enable **online fitness coaching**, and support **e-commerce for gym products**.  
This system combines smart management tools, AI-powered fitness assistance, and an online store — all in one unified solution.

---

## 🚀 Features

### 🔧 Core Gym Management
- Register and manage gym members  
- Handle memberships, renewals, and payments  
- Schedule and manage training sessions  
- Generate attendance and performance reports  

### 💪 Online Coaching
- Coaches can create personalized workout and diet plans  
- Members can view plans, track progress, and communicate with trainers  
- AI Chatbot answers fitness and nutrition questions in real-time  

### 🛒 E-Commerce Module
- Online store for gym equipment, supplements, and protein products  
- Secure online payments via Stripe / PayPal  
- Order management and transaction history  

---

## 🧠 AI Chatbot Assistant
A built-in **AI chatbot** powered by **OpenAI API**, trained to provide:
- Workout and diet guidance  
- Supplement recommendations  
- Exercise form and recovery advice

## ⚙️ Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend (Web)** | React.js |
| **Backend (API)** | ASP.NET Core Web API |
| **Database** | Microsoft SQL Server |
| **Mobile App** | React Native |
| **Authentication** | JWT (JSON Web Token) |
| **AI Chatbot** | OpenAI API |
| **Hosting / Deployment** | Azure / AWS / Vercel (optional) |

---

## 🧩 System Modules

1. **Admin Dashboard** – Manage trainers, members, and finances  
2. **Trainer Portal** – Manage clients, upload and edit workout/diet plans  
3. **Member Portal** – View assigned plans, progress, and make payments  
4. **E-Commerce** – Browse and purchase gym-related products online  
5. **AI Chatbot** – 24/7 interactive virtual fitness assistant
